# Extra documents for the chat box

Put any `.md` or `.txt` file here (sub-folders are fine): price lists, sales policies, FAQs,
new project descriptions... Restart the server and the chat box reads and searches them.

Tips for accurate answers:
- One topic per section, starting with a clear `## Heading` (e.g. `## Discount policy for project X`).
- Write proper names in full in the text (project names, district names), since the search is keyword based.
- Write the documents in the language your customers ask in (Vietnamese for the sample data).

This `README.md` file is not given to the chat box.
