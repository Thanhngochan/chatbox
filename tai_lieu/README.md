# Thư mục tài liệu thêm cho chat box

Bỏ vào đây bất kỳ file `.md` hoặc `.txt` nào (có thể chia thư mục con): bảng giá, chính sách bán hàng,
câu hỏi thường gặp, giới thiệu dự án mới... Khởi động lại server là chat box tự đọc và tìm trong đó.

Mẹo để chat box trả lời đúng:
- Mỗi chủ đề một mục bắt đầu bằng `## Tiêu đề rõ ràng` (ví dụ `## Chính sách chiết khấu dự án X`).
- Viết tên riêng đầy đủ trong nội dung (tên dự án, tên quận) vì chat box tìm theo từ khoá.

File `README.md` này không được đưa vào chat box.
